# Deine Fantasy-Life-Mod-Werkstatt

Hier kannst du kleine Spielideen bauen lassen. Du brauchst keine Programmierkenntnisse.
Du beschreibst deine Idee in Freebuff. Dein Agent baut sie. Du probierst sie aus.
Leo entscheidet, ob sie ins normale Spiel kommt.

## Einmal einrichten

1. Bitte Leo zuerst um eine Einladung zu seinem **privaten** GitHub-Projekt.
   Leo muss zuerst die Werkzeuge ins Modding-Kit übertragen.
2. Nimm die Einladung an. Öffne deinen normalen Spielordner:
   Drücke **Windows + R**, füge `%LOCALAPPDATA%\FantasyLife-PC\contrib` ein,
   drücke **Enter**. Doppelklicke **Setup-Contrib.bat**.
3. Es öffnet sich ein Textfenster. Es prüft Git, Python und GitHub CLI.
   Das sind Hilfsprogramme für deinen Agenten. Vor jeder Installation fragt es dich.
   Tippe **j**, dann **Enter**, wenn du einverstanden bist.
4. Wenn sich der Browser öffnet, melde dich mit **deinem** GitHub-Konto an.
   Bestätige die Anmeldung. Gib Passwörter nur auf der GitHub-Seite ein.
5. Warte auf **Du bist bereit!**. Das Lesen deines eigenen Spiels kann dauern.
   Am Ende steht der Ordner, den du öffnen sollst.

Steht dort „Leo muss zuerst …“, zeige Leo die Meldung. Du hast nichts falsch gemacht.
Bei einer anderen Fehlermeldung: Fenster offen lassen und Leo oder deinem Agenten
den Text zeigen. Du kannst das Setup später erneut starten. Es behält deine Arbeit.

## Eine Idee bauen

1. Starte Freebuff. Wähle **Open Folder / Ordner öffnen** (die Bezeichnung kann
   je nach Version abweichen). Füge `%APPDATA%\FantasyLife-Contrib` in die
   Ordnerauswahl ein und bestätige **Ordner auswählen / Öffnen**.
   Das ist der ganze Werkstattordner, nicht nur der Unterordner `modkit`.
   Die Desktop-Verknüpfung **Fantasy Life Mod Workshop** öffnet diesen Ordner auch.
   Wenn du keine Ordnerauswahl findest, bitte Leo, sie dir einmal zu zeigen.
2. Starte einen Chat. Schreibe zum Beispiel:
   **„Lies zuerst AGENTS.md. Ich möchte ein Feuerschwert, ungefähr so stark wie
   das Holzschwert. Es soll im Laden erhältlich sein.“**
3. Dein Agent fragt jeweils eine einfache Frage und erklärt den Plan.
   Du kannst „Such du etwas Passendes aus“ sagen. Bestätige den Plan, wenn er passt.
4. Wenn dein Agent „bereit zum Testen“ schreibt, schließe laufende Spiel-Fenster.
   Doppelklicke auf dem Desktop auf **Fantasy Life (Test)**.
   Folge seiner kurzen Liste. Dein normales Spiel und seine Spielstände bleiben
   unberührt. Die Testversion hat eigene Spielstände.
5. Beschreibe, was du gesehen hast: zum Beispiel „Der Name stimmt, aber das
   Schwert ist unsichtbar“. Der Agent verbessert es, dann testest du erneut.
6. Wenn alles passt, schreibe **„Fertig, schick es an Leo.“** Der Agent schickt
   Leo einen Änderungsvorschlag und gibt dir einen Link. Leo prüft und entscheidet.
   Der Vorschlag ist noch kein normales Spielupdate.

Wenn etwas kaputt aussieht: Testspiel schließen. Sage dem Agenten, was zuletzt
funktioniert hat und was passiert ist. Bitte ihn bei Bedarf: **„Setze die Testversion
auf die normalen Mods zurück.“** Lösche keine Ordner oder Spielstände.
Du kannst dein normales **Fantasy Life** weiter starten.

Nach einem normalen Spielupdate kannst du **Setup-Contrib.bat** erneut starten.
So bekommt dein Agent die neueste Anleitung. Das normale Spiel erinnert dich nicht daran.
Gib niemals den ganzen Werkstattordner oder deine Spiel-Dumps weiter.

# Your Fantasy Life Mod Workshop

You can make small game ideas without knowing how to code. Describe your idea in
Freebuff. Your agent builds it. You try it. Leo decides whether it joins the normal game.

## Set up once

1. Ask Leo for an invitation to his **private** GitHub project. He must export
   the tools into the modding kit first. Accept the invitation with your own GitHub account.
2. Press **Windows + R**. Paste `%LOCALAPPDATA%\FantasyLife-PC\contrib` and press
   **Enter**. Double-click **Setup-Contrib.bat**.
3. A text window checks Git, Python and GitHub CLI. These help your agent work.
   It asks before each installation. Type **y**, then **Enter**, if you agree.
4. When the browser opens, sign in to **your** GitHub account and approve the login.
   Enter your password only on GitHub's website.
5. Wait for **You're ready!** Reading your own game can take a while.
   The window shows the folder to open.

If it says Leo must fill in the address, show him the message. For any other error,
keep the window open and show the text to Leo or your agent. You can rerun setup;
it keeps your work.

## Make something

1. Open Freebuff. Choose **Open Folder** (the exact label may vary by version).
   Paste `%APPDATA%\FantasyLife-Contrib` into the folder picker. Click **Select
   Folder / Open**. Open the whole workshop, not just `modkit` inside it.
   **Fantasy Life Mod Workshop** on your desktop also opens that folder.
   Ask Leo to show you the folder picker once if you cannot find it.
2. Start a chat: **“Read AGENTS.md first. I'd like a fire sword about as strong
   as the Wooden Sword. I'd like to buy it in a shop.”**
3. Your agent asks one simple question at a time and explains the plan.
   You can say “Pick something suitable.” Agree to the plan when it looks right.
4. When the agent says it is ready, close any running game windows.
   Double-click **Fantasy Life (Test)** on your desktop. Follow the short test list.
   Your normal game and its saves stay untouched. The test game has its own saves.
5. Tell your agent what happened, for example “The name is right, but the sword
   is invisible.” It makes changes, then you try again.
6. When you are happy, say **“Done, send it to Leo.”** Your agent sends a proposed
   change and shares its link. Leo reviews and decides. This is not a normal game
   update yet.

If something looks broken, close the test game. Tell your agent what last worked
and what happened. You can ask **“Reset the test install to the normal mods.”**
Do not delete folders or saves. You can still launch normal **Fantasy Life**.

After a normal game update, rerun **Setup-Contrib.bat** to refresh your agent's
instructions. The game will not remind you. Never share your whole workshop or dumps.
